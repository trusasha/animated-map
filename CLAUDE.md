# Как пишем Trip Animator

Продукт и бизнес-правила — `PROJECT.md`. Здесь — как устроен код.

## Слои

```
src/
  ds/          UI-дизайн-система: токены (CSS-переменные) + примитивы (Button, Input, Slider, Segmented, Dialog…). Не знает о поездках.
  domain/      бизнес-логика: чистые функции и типы (цепочка маршрута, таймлайн, правила участков). Без React, без библиотек, без сети. Покрыта *.check.ts.
  services/    адаптеры к внешнему миру, каждый за своим интерфейсом:
    map/       MapService — единственное место, где импортируется maplibre-gl
    scene3d/   3D-движок фигурок и миниатюр — единственное место с three
    video/     кодирование MP4 — единственное место с mp4-muxer / WebCodecs
    api/       HTTP-клиент к нашему серверу
  features/    фичи (trips, route, figures, preview, export): hooks/ — состояние и оркестрация, components/ — глупые компоненты фичи
  app/         композиция: собирает фичи и сервисы, точка входа
server/
  db/          DbService: интерфейс + провайдеры (pglite, postgres/Supabase). Только здесь импорты драйверов БД
  …            остальные внешние API (OpenAI, fal.ai, геокодеры, OSRM) — каждый в своём сервисе
```

Направление зависимостей: `app → features → (domain, services, ds)`; `services → domain`; `domain` и `ds` ни от кого не зависят.

## Правила

- **Компоненты глупые.** Только props → разметка и колбэки наружу. Никаких запросов, сервисов, бизнес-правил и глобального состояния внутри компонента. Логика — в хуках фичи или в `domain/`.
- **Бизнес-правило живёт в `domain/` один раз.** Хук вызывает его, компонент о нём не знает.
- **Библиотеки — только через свой сервис.** Импорт maplibre, three, драйвера БД, SDK внешнего API вне его сервиса — ошибка. Интерфейс сервиса описан нашими типами, чтобы провайдера можно было сменить (PGlite → Supabase, другой картографический движок) без правок в фичах.
- **Файл ≤ 200 строк.** Больше — декомпозируем: хук, хелпер, подкомпонент. Исключение допустимо с причиной (например, таблица данных процедурной 3D-модели).
- **Повторилось дважды — выносим** в хук или хелпер. Общие хелперы без бизнес-смысла — `src/lib/`.
- **Дизайн-система первая.** Новый UI собирается из примитивов `ds/`; цвета, отступы, радиусы, шрифты — только через токены, без литералов в компонентах.
- **Проверка.** Нетривиальная логика `domain/` оставляет `*.check.ts`, который подключён в `npm run check`.
